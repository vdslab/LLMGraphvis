# LLMGraph-vis 仕様書

## 1. はじめに

このドキュメント群は、LLMGraph-visアプリケーションの技術仕様を定義します。

**LLMGraph-vis**は、ユーザーがグラフ（ネットワーク）構造をインタラクティブに可視化し、大規模言語モデル（LLM）との対話を通じて分析を行うためのWebアプリケーションです。研究者や開発者が、専門的な知識なしにグラフの特徴を把握したり、インサイトを得たりすることを目的としています。
