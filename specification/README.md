# 仕様書

このディレクトリには、LLMGraph-visアプリケーションの各コンポーネントに関する仕様書が含まれています。

## ドキュメント一覧

- **[アーキテクチャ設計](./architecture.md)**
  - システム全体の構成、C4モデル（コンテキスト図、コンテナ図）、コンポーネント図、シーケンス図を記述しています。

- **[バックエンド仕様 (API)](./backend.md)**
  - FastAPIで構築されたバックエンドAPIのエンドポイント、データモデル、認証フロー、外部サービス連携について記述しています。

- **[フロントエンド仕様 (Frontend)](./frontend.md)**
  - Reactで構築されたフロントエンドの画面構成、コンポーネント、状態管理、API連携について記述しています。

- **[グラフ計算サービス仕様 (NetworkXMCP)](./network_analysis.md)**
  - グラフ計算を担当する`NetworkXMCP`マイクロサービスの役割、APIエンドポイント、主要な機能について記述しています。
