# 0011. 内部言語と会話言語の分離

- **状態**: 採用
- **日付**: 2026-09-12

## 背景

英語の質問に対して日本語の質問フォームが返る。手順中の日本語例と固定表示が、ユーザーの言語選択に干渉していた。

## 決定

内部指示・手順の例・ツール説明・固定 UI は英語を基本とする。会話本文と生成する質問・ラベル・選択肢は、明示された言語指定を優先し、それ以外は現在のユーザーの質問に合わせる。判別できない場合のみ会話の直近の言語、最終的に英語を使う。

日本語を認識するトリガー・入力検出は維持する。仕様書は既存方針どおり日本語で記述する。

## 根拠

例文や過去の返答に言語を引きずられず、会話中の言語変更を尊重するため。固定 UI の多言語化は今回導入せず、英語のインターフェースと多言語の会話を分離する。

## 帰結

共通の言語方針は常時ロードするプロンプトに置く。Skills と ask_user はこの方針に従い、属性名や ID、ユーザーの入力値は翻訳しない。保存済みの会話・フォーム本文は書き換えない。
