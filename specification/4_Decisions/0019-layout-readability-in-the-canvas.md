# 0019. 描画した配置の読みやすさをキャンバスから確認できるようにする

- **状態**: 採用
- **日付**: 2026-09-25
- **関連**: [0017](./0017-layout-quality-metrics.md)（描画結果の評価）、[0018](./0018-layout-tuning-choice.md)（調整の進め方）

## 背景

0017 で配置の品質指標を計算できるようになったが、指標は主にエージェントへ渡され、
画面上には配置アルゴリズム名しか表示されない。利用者は「重なりが多い」という
エージェントの説明を、現在の図の具体的な状態と結びつけにくい。
また、ノードサイズを変更すると重なりも変わるが、配置を再計算しなければ品質指標が
更新されない経路がある。

## 決定

描画を返す可視化ツールは、同じ描画データに対する `layout_quality` を返す。
フロントエンドはこれをネットワーク状態の一部として保存し、配置名の近くに
読みやすさの要点を表示する。詳しい数値は利用者が開いたときだけ見せる。

品質指標はネットワーク間の優劣を示す成績表として扱わない。問題の種類、
ノードの重なり、エッジの交差などを現在の図を読むための情報として示す。
指標がない古い保存データでは、配置名だけを表示する。

## 根拠

現在の図と同じ描画データから計算すれば、ノードサイズや表示対象が変わった後も
説明が古くならない。キャンバス上では要点だけを常時見せることで、分析の邪魔をせず、
詳しく知りたい利用者には指標と意味を確認する入口を用意できる。

却下した代替案:
- **エージェントの説明だけに任せる**: 会話を遡る必要があり、表示中の図が変わると対応が分からなくなる。
- **総合スコアを大きく表示する**: 0017 のスコアは同じネットワークの配置比較にしか使えず、別のネットワークとの比較を誘発する。

## 帰結

- 描画ペイロードとフロントエンドのネットワーク状態は `layout_quality` を含めて上書きする。
- フロントエンドで品質を再計算しない。指標の定義と閾値は NetworkX API に置く。
- 可視化ツールの描画経路、ネットワークストア、配置情報の表示を一緒に変更する。
