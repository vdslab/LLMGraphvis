# 0048. 力学モデル系のレイアウトの後に、ノードの重なりを取り除く

- **状態**: 採用
- **日付**: 2026-11-16

## 背景

ADR 0047 で、3,383 ノードの埋め込みシラバスの初期レイアウトを spring にした。
科目群のまとまりは見えるようになったが、`layout_quality` の `node_overlap` は 0.92 だった。
つまり、ほとんどのノードが他のノードに重なっている。

調べると、これはレイアウトのパラメータでは直らない。

- 描画は座標を [-1000, 1000] に引き伸ばし直す（ADR 0017）。spring の `k` を 2 倍、4 倍にしても、
  重なりは 0.93 のまま変わらなかった。全体の広がりが変わらないためである。
- 画面の広さが足りない。この規模とノードサイズでは、一様ランダムに並べても 54% が重なる。
  spring の配置では、最も近いノードまでの距離の中央値が 6.9 で、
  重ならないには 16 以上の間隔が要る。
- ノードを小さくする余地もない。画面上の半径はすでに約 3 px である。

重なったノードは隠れて見えず、塊の大きさ（そこに何ノードあるか）も読めなくなる。

## 決定

- **力学モデル系のレイアウト（spring、ForceAtlas2、ARF、Kamada-Kawai）の後に、
  重なっているノード同士を押し離す処理をかける。** 処理は描画と同じ座標系
  （`normalize_like_renderer`）で行い、離す距離は、その時点で描いているノードのサイズから決める。
  結果は元のレイアウトの座標系に戻して保存する。
- **どのレイアウトにかけるかは `@register` で宣言する**（`removes_overlap`）。
  円形やグリッド、二部グラフのように、位置そのものに意味がある配置にはかけない。
- **利用者は `remove_overlap=False` で外せる。** 既定は有効である。
- **キャッシュのキーには、`remove_overlap` とノードサイズの要約を含める。**
  サイズの割り当てを変えた後にレイアウトを呼び直すと、新しいサイズで離し直す。
- **`layout_suggest_parameters` の候補も、同じ処理をかけてから採点する。**
  描かれるものを採点するためである（ADR 0017）。

## 根拠

押し離す処理だけを、アプリの配置に後からかけて測った（ホスト）。

| データ | レイアウト | 重なり（前 → 後） | edge_locality（前 → 後） | 時間 |
|---|---|---|---|---|
| 埋め込みシラバス 3,383 | spring | 0.93 → 0.13 | 0.09 → 0.10 | 2 秒 |
| 旧シラバス 3,393 | spring | 0.66 → 0.09 | 0.04 → 0.05 | 2 秒 |
| Les Misérables 77 | ForceAtlas2 | 0.05 → 0.00 | 変化なし | 0 秒 |
| 演奏会 1,144 | ForceAtlas2 | 0.97 → 0.75 | 0.31 → 0.36 | 1 秒 |

埋め込みシラバスの科目群のまとまりは 0.396 から 0.405 で、ほぼ変わらなかった。
画像で見ても塊の形は残り、隠れていたノードが面として見えるようになった。

演奏会で効きが弱いのは、少数の遠いノードのせいで、残りが画面の 4% に押し込まれているためである
（`core_extent` 0.04）。これは重なりとは別の問題（`outliers_compress_core`）である。

却下した代替案:

- **`k` などのパラメータで広げる。** 描画が座標を引き伸ばし直すので、効かない。
- **既定のノードサイズを小さくする。** 画面上ですでに半径約 3 px で、これ以上は見えなくなる。
- **描画時（`visualization_generate`）に離す。** 保存した座標と描いた座標が食い違い、
  `init_from_layout` やレイアウトのキャッシュが、描かれていない配置を指すことになる。
- **ForceAtlas2 の `size_aware` を既定にする。** ForceAtlas2 にしかなく、実行時間がほぼ倍になる。

## 帰結

- 力学モデル系のレイアウトの保存座標は、重なりを取り除いた後のものになる。
  `remove_overlap` が入る前のキャッシュは、次の呼び出しで一度だけ計算し直される。
- 後からノードサイズを変えると、また重なることがある。skill `layout` は、
  そのときレイアウトを呼び直すよう指示する。
- 定数（反復回数、余白）は `networkx-api/app/logic/layouts/overlap.py` にある。
